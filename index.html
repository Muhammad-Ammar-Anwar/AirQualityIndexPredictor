📁 Project File Structure
10pearls/ — AQI SeekAI Karachi
⚙️ Core Pipeline
📄 Fetch_Historical_Data.py Fetches hourly weather + AQ data from Open-Meteo API in 30-day chunks
📄 feature_engineering.py Builds 120+ ML features — lags, rolling stats, wind u/v, time encoding, interactions
📄 Complete_Pipeline.py One-shot backfill: fetch API → merge MongoDB → engineer → save CSV → upload
📄 hourly_pipeline.py Runs every hour: fetch last 3h → dedup → engineer → upload new records
📄 Model_Retrain_pipeline.py Retrains every 72h: compare XGBoost/LightGBM/RF → train winner → save to MongoDB
📄 mongodb_upload.py MongoDB helper — batch upload, dedup on datetime, type conversion
🌐 API & Frontend
📄 backend.py FastAPI — /api/current, /api/forecast, /api/historical, /api/eda, /api/model-info
📄 index.html Single-page dashboard — Dashboard, Forecast, Historical, Analytics, Model Info
📄 app.py Streamlit app — alternative local exploration UI
🗄️ Data
📊 Mongodb vector store Feature-engineered dataset (120+ cols) — primary model training input
🔒 .env MONGODB_URI, MONGODB_DB, collection names — not committed to git
🔄 CI/CD — .github/workflows/
📄 hourly_api_fetch.yml GitHub Actions — triggers hourly_pipeline.py every hour
📄 72h_retrain.yml GitHub Actions — triggers Model_Retrain_pipeline.py every 72h
📦 Config & Deps
📄 requirements.txt Python deps — fastapi, xgboost, lightgbm, scikit-learn, pymongo, pandas
🏗 Pipeline Architecture
Algorithm XGBoost — Gradient Boosted Trees
Strategy 120+ features engineered from raw inputs — AQI lags (1/3/6/12/24h), rolling mean/std (6/12/24h), wind u/v decomposition, cyclical time encoding, weather derivatives, sub-AQI indices, and 7 interaction terms
Model Selection All 3 models trained on probe horizons (t+1, t+6, t+24, t+48) — winner picked by avg RMSE
Feature Scaling RobustScaler — fit on training set only
Lag Exclusion Lags shorter than horizon excluded per model (no leakage)
Weather Injection Open-Meteo 72h forecast injected at inference time
Early Stopping 10% internal validation split, 50-round patience
Retrain Frequency Every 72 hours via GitHub Actions workflow
Data Source Open-Meteo Air Quality API — Karachi (24.86°N, 67.00°E)
